EUNOIA Massage — คู่มือขึ้นเว็บจริง

ทำตามทีละข้อ ประมาณ 20–25 นาที · ฟรีทั้งหมด ไม่ต้องผูกบัตร

ทำเสร็จ 0 จาก 4 ขั้น

ทำไมต้องทำเองบางส่วน: ขั้นตอนพวกนี้ต้องล็อกอินด้วยบัญชีของพี่เอง (Supabase / GitHub / Vercel) ซึ่งเป็นเจ้าของข้อมูลและเจ้าของเว็บ — ฉันเข้าบัญชีแทนไม่ได้ แต่โค้ดและไฟล์ SQL เตรียมไว้ให้ครบแล้ว เหลือแค่ก๊อป-วาง-กด
1

สร้างฐานข้อมูล (Supabase)

ประมาณ 7 นาที · ที่เก็บข้อมูลจริงของร้าน

  1. เข้า supabase.com → กด Start your project → เข้าด้วยบัญชี Google ของร้าน
  2. กด New project · ชื่อ eunoia · Database Password ตั้งรหัสแล้วจดเก็บไว้ · Region เลือก Southeast Asia (Singapore) (ใกล้ไทยที่สุด = เร็วที่สุด) → Create new project → รอประมาณ 2 นาที
  3. เมนูซ้าย → SQL Editor → New query
  4. เปิดไฟล์ ติดตั้งใช้งานจริง.sql → คัดลอกทั้งไฟล์ → วางในช่อง → กด Run (หรือ Ctrl/⌘ + Enter)
    ต้องเห็นคำว่า Success · ถ้ามีข้อความ NOTICE สีเหลืองไม่ต้องกังวล เป็นเรื่องปกติ
    อยากลองเล่นก่อนด้วยข้อมูลตัวอย่าง ให้ใช้ไฟล์ ติดตั้งพร้อมข้อมูลตัวอย่าง.sql แทน
  5. ปิดการยืนยันอีเมล → เมนู Authentication → Sign In / Providers → Email → ปิดสวิตช์ Confirm email → Save
    ข้อนี้สำคัญมาก — ถ้าไม่ปิด พอสมัครบัญชีแล้วจะเข้าใช้งานไม่ได้จนกว่าจะไปกดลิงก์ยืนยันในอีเมล ซึ่งพนักงานหน้าร้านมักไม่มีอีเมลร้าน
  6. ไปที่ Project Settings (รูปเฟือง) → API → คัดลอกเก็บไว้ 2 ค่า:
    ชื่อค่าหน้าตาประมาณนี้
    Project URLhttps://abcdxyz.supabase.co
    anon public key
    (บางหน้าเขียนว่า publishable key)    		eyJhbGciOi… หรือ sb_publishable_… (ยาวมาก)
    คีย์ตัวนี้ปลอดภัยที่จะอยู่ในเว็บ เพราะระบบล็อกสิทธิ์ไว้ที่ฐานข้อมูล (RLS) แล้ว — ห้ามใช้ค่า service_role เด็ดขาด

อัปโหลดโค้ด (GitHub)

ประมาณ 5 นาที · ที่เก็บโค้ด เพื่อให้เว็บอัปเดตได้ทีหลัง

  1. แตกไฟล์ eunoia-production.zip ให้เรียบร้อยก่อน (จะได้โฟลเดอร์ที่มี package.json อยู่ชั้นบนสุด)
  2. เข้า github.com/signup → สมัครฟรี (ถ้ามีบัญชีแล้วข้ามไป)
  3. กด + มุมขวาบน → New repository · ชื่อ eunoia-massage · เลือก Private → Create repository
  4. ในหน้าที่เพิ่งสร้าง กดลิงก์ uploading an existing file
  5. ลากไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างในโฟลเดอร์ที่แตกไว้ (ไม่ใช่ลากตัวโฟลเดอร์) มาวางในกรอบ → รอขึ้นครบ → กด Commit changes
    เช็กว่าในหน้า repo เห็นไฟล์ package.json อยู่ชั้นบนสุด ถ้าเห็นเป็นโฟลเดอร์ชื่อ eunoia ชั้นเดียวแทน Vercel จะหาโปรเจกต์ไม่เจอ — ให้ลบแล้วลากใหม่จากข้างในโฟลเดอร์
3

เอาขึ้นเว็บ (Vercel)

ประมาณ 5 นาที · ได้ลิงก์เว็บจริงที่เปิดจากที่ไหนก็ได้

  1. เข้า vercel.com/signup → Continue with GitHub → อนุญาตให้เข้าถึง
  2. กด Add New… → Project → หา eunoia-massage → Import
  3. เปิดหัวข้อ Environment Variables แล้วใส่ 2 ค่า (ชื่อต้องตรงตัวพิมพ์ใหญ่-เล็ก):
    NEXT_PUBLIC_SUPABASE_URL
    NEXT_PUBLIC_SUPABASE_ANON_KEY
    ช่อง Value ใส่ Project URL และ anon key จากขั้นที่ 1 ตามลำดับ
  4. กด Deploy → รอประมาณ 2 นาที → ขึ้นรูปพลุ 🎉 แล้วได้ลิงก์ https://eunoia-massage.vercel.app
ทีหลังอยากแก้อะไร — บอกฉันได้เลย ฉันส่งไฟล์ที่แก้แล้วให้ พี่อัปทับใน GitHub (กดที่ไฟล์ → รูปดินสอ → วางทับ → Commit) แล้ว Vercel จะอัปเดตเว็บให้เองภายใน 2 นาที ไม่ต้องทำขั้นที่ 1–3 ใหม่
4

เปิดใช้งานวันแรก

ประมาณ 5 นาที

  1. เปิดลิงก์เว็บ → กด สมัครบัญชี → ใส่อีเมล + รหัสของพี่
    บัญชีแรกที่สมัคร = เจ้าของร้านอัตโนมัติ (เห็นการเงิน แก้ราคา ยกเลิกรายการ ปิดวันได้) คนที่สมัครหลังจากนั้นจะเป็น พนักงานหน้าร้าน เอง — ดังนั้นให้พี่สมัครก่อนคนอื่นเสมอ
  2. ตั้งค่าระบบ → หมอนวด → เพิ่มชื่อหมอนวดจริงทั้งหมด
  3. ตั้งค่าระบบ → บริการ → ตรวจราคาและค่าแรงให้ตรงกับร้าน
    ยังค้างรอพี่ยืนยัน: ค่าแรง นวดน้ำมันมะพร้าวร้อน ฿600 · ขัดส้นเท้า ฿500/30 นาที · นวดหน้าและหัว ฿800 (ตอนนี้ใส่ ฿180 / ฿100 / ฿180 ไว้ก่อน) และ นวดหน้า ยังปิดใช้งานอยู่เพราะไม่มีราคา
  4. ตั้งค่าระบบ → ทั่วไป → เลือกว่าครบเวลาแล้วให้ปิดงานเองทันที หรือผ่อนผันกี่นาที
  5. ตั้งค่าระบบ → Google Sheets → ทำตามขั้นตอนในหน้านั้น (วางโค้ดจาก EUNOIA-AppsScript.gs ในชีต → เอาลิงก์ /exec มาวาง) → กด ทดสอบการเชื่อมต่อ
  6. ให้พนักงานเปิดลิงก์เดียวกันแล้ว สมัครบัญชีของตัวเอง — ได้สิทธิ์พนักงานหน้าร้านอัตโนมัติ
  7. บน iPad: เปิดลิงก์ใน Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม → ใช้เหมือนแอปเต็มจอ

แก้ปัญหาที่อาจเจอ

สมัครบัญชีแล้วเข้าไม่ได้ / ขึ้นว่าต้องยืนยันอีเมล

ยังไม่ได้ปิด Confirm email ในขั้นที่ 1 ข้อ 5 — ปิดแล้วสมัครใหม่อีกครั้ง

เปิดเว็บแล้วขึ้นหน้าขาว หรือขึ้น error เรื่อง Supabase

ชื่อ Environment Variables พิมพ์ไม่ตรง หรือใส่ค่าสลับกัน → Vercel → Settings → Environment Variables → แก้ให้ตรง แล้วไปแท็บ Deployments กด Redeploy (ต้อง Redeploy ทุกครั้งที่แก้ค่าพวกนี้)

Vercel ขึ้น Build Failed

เกือบทุกครั้งเกิดจากไฟล์อัปไม่ครบ หรือโครงสร้างโฟลเดอร์ซ้อนกัน — เช็กว่าใน repo มี package.json, โฟลเดอร์ src และ next.config.mjs อยู่ชั้นบนสุด ถ้าไม่ใช่ให้ลากไฟล์ขึ้นใหม่

ส่งเข้า Google Sheets ไม่สำเร็จ

ตอน Deploy ใน Apps Script ต้องเลือก ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน (Anyone) และใช้ลิงก์ที่ลงท้ายด้วย /exec · รหัสลับต้องตรงกับบรรทัด SECRET ในโค้ด · แก้แล้วกดส่งซ้ำได้เลย ยอดในระบบไม่หาย

ค่าใช้จ่าย

Supabase และ Vercel มีแพ็กเกจฟรีที่เพียงพอกับร้านขนาดนี้สบาย ๆ ไม่ต้องผูกบัตร · ถ้าวันหนึ่งอยากใช้ชื่อเว็บของร้านเอง (เช่น eunoia.com) ค่อยซื้อโดเมนแล้วผูกกับ Vercel ได้

ข้อมูลปลอดภัยแค่ไหน

ข้อมูลอยู่ในฐานข้อมูลของพี่เอง · พนักงานหน้าร้านเห็นหน้าการเงินไม่ได้ · ลบรายการเงินไม่ได้เลย (ยกเลิกได้เฉพาะเจ้าของร้าน และต้องใส่เหตุผล) · ทุกการแก้ไขราคา/ค่าแรง/หมอนวด ถูกบันทึกว่าใครแก้ตอนไหน
